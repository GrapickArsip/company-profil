# Company Profil

Website **Company Profile** yang dibuat untuk menampilkan informasi perusahaan secara profesional, informatif, dan mudah diakses oleh pengunjung.

## 📌 Tentang Project

Project ini merupakan website company profile yang dapat digunakan untuk memperkenalkan perusahaan, menampilkan informasi layanan, portofolio, profil, dan kontak.

## ✨ Fitur

* 📱 Tampilan responsif
* 🏢 Halaman profil perusahaan
* 💼 Informasi layanan
* 🖼️ Portofolio atau proyek
* 📞 Informasi kontak
* 🧭 Navigasi yang mudah digunakan
* ⚡ Tampilan cepat dan modern

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/grapick505-jpg/company-profil.git
```

### 2. Masuk ke Folder Project

```bash
cd company-profil
```

### 3. Jalankan Project

Jika project menggunakan HTML statis, buka file `index.html` menggunakan browser.

Jika menggunakan teknologi atau framework lain, jalankan sesuai konfigurasi project.
